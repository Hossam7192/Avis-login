# 🚗 Avis Car Rental – Flet UI Project

This project is a simplified UI clone inspired by **Avis Car Rental**.  
It was created as part of a UI/UX course to demonstrate page navigation, form handling, and clean interface design using **Flet**.

---

## 📌 Project Overview

### Included Pages:
- **Home page**
- **Login page**
- **Create account (Register) page**

### What the project showcases:
- Basic UI layout design
- Navigation between pages using `page.go()`
- Simple form validation (names, email, password, age)
- Clean light-mode interface suitable for academic presentation

---

## ✨ Features

✔️ Sign in form with validation  
✔️ Create account form with data validation  
✔️ Gender dropdown selection  
✔️ Age verification (must be 18+)  
✔️ Route-based navigation  
✔️ Minimal UI suitable for UX coursework
